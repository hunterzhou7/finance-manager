## 1. 产品介绍

### 1.1 产品定位

财务管家是一款轻量级的个人与家庭财务管理工具，帮助用户快速记录日常消费与收入，提供直观的统计分析和财务报表，让每一笔收支都有迹可循。

无论您是希望控制日常开支的个人，还是需要管理家庭共同财务的夫妻，抑或是记录经营收支的小微企业主，财务管家都能为您提供清晰的财务管理方案。

### 1.2 产品组成

财务管家包含三个客户端，满足不同场景的使用需求：

| 客户端       | 访问方式   | 适用人群             | 端口 |
| ------------ | ---------- | -------------------- | ---- |
| **用户端**   | 浏览器访问 | 普通用户记录收支     | 3000 |
| **管理后台** | 浏览器访问 | 运营人员管理用户数据 | 3002 |
| **移动APP**  | 手机安装   | 随时随地记账         | —    |

### 1.3 核心价值

- **简单高效**：3秒钟完成一笔记账，告别繁琐流程
- **一目了然**：本月收支、分类占比、趋势变化尽在掌握
- **数据导出**：支持Excel导出，方便对账和存档

## 3. 用户操作说明

### 3.1 首次使用

#### 3.1.1 注册账号

1. 打开用户端登录页
2. 点击「注册账号」入口
3. 填写用户名、密码、确认密码、昵称
4. 点击「注册」完成注册

#### 3.1.2 首次记账

1. 登录后进入首页
2. 点击「+ 记一笔」按钮
3. 选择「支出」或「收入」
4. 选择分类
5. 输入金额
6. 点击「保存」

### 3.2 日常使用

#### 3.2.1 查看本月收支

每次打开APP或网页，首页自动展示本月收入、支出、结余金额。

#### 3.2.2 快速记账

1. 进入「记一笔」页面
2. 选择收支类型
3. 选择分类
4. 输入金额
5. 可选：选择账户、添加备注、选择日期
6. 保存

#### 3.2.3 查看统计

1. 进入「统计」页面
2. 选择年份
3. 查看年度收支汇总
4. 查看分类占比饼图
5. 查看月度趋势图

#### 3.2.4 导出数据

1. 进入「明细」页面
2. 筛选需要的记录条件
3. 点击「导出Excel」
4. 下载生成的Excel文件

### 3.3 分类与账户管理

#### 3.3.1 添加自定义分类

1. 进入「分类管理」页面
2. 点击「添加分类」
3. 选择「支出」或「收入」
4. 输入分类名称
5. 选择图标和颜色
6. 保存

#### 3.3.2 添加账户

1. 进入「账户管理」页面
2. 点击「添加账户」
3. 输入账户名称
4. 选择图标和颜色
5. 输入初始余额（可选）
6. 保存

## 5. 常见问题

### 5.1 账号问题

**Q: 如何注册新账号？**
A: 在登录页点击「注册账号」，填写用户名、密码、昵称后提交即可。

**Q: 忘记密码怎么办？**
A: 目前版本暂不支持找回密码，请使用新账号注册。如需帮助，请联系管理员。

**Q: 可以同时登录多个设备吗？**
A: 可以，不同设备使用同一账号登录即可同步数据。

### 5.2 记账问题

**Q: 可以补录之前的消费吗？**
A: 可以，在记一笔页面点击日期可选择历史日期。

**Q: 记账后可以修改吗？**
A: 可以，在明细页面找到对应记录，点击编辑即可修改。

**Q: 删除记录会退还金额吗？**
A: 删除交易记录会同时更新相关账户的余额。

### 5.3 数据问题

**Q: 数据存储在哪里？**
A: 数据存储在服务器MySQL数据库中，永不超过期。

**Q: 可以导出数据吗？**
A: 可以，在明细页面点击「导出Excel」即可下载。

**Q: 换个手机数据还在吗？**
A: 只要登录同一个账号，数据会自动同步。

### 5.4 管理后台问题

**Q: 管理后台的账号密码是什么？**
A: 管理后台需要单独申请，由管理员分配账号。

**Q: 可以查看所有用户的数据吗？**
A: 可以，管理后台可以查看所有用户的交易和统计数据。
