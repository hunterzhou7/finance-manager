# 财务管家 - 前端Web应用测试计划

## 1. 项目概述

| 项目 | 财务管家 Web前端 |
|------|----------------|
| 位置 | 003.前端代码（前端工程师）/frontend |
| 类型 | 单页HTML/CSS/JS Web应用 |
| 端口 | 本地文件直接访问 |

## 2. 技术栈分析

- **UI框架**: 原生HTML + Tailwind CSS (CDN)
- **字体**: Plus Jakarta Sans, Material Symbols Outlined
- **图表**: Chart.js
- **存储**: localStorage（无后端，本地存储）
- **路由**: 页面跳转（hash或直接链接）

## 3. 目录结构

```
frontend/
├── index.html            # 入口/导航页
├── pages/
│   ├── login.html      # 登录
│   ├── register.html  # 注册
│   ├── dashboard.html  # 首页

│   ├── statistics.html # 统计

│   ├── main.css
│   └── design-tokens.js
├── js/
│   ├── app.js
│   └── components/
└── assets/
```

## 4. 启动方式

直接用浏览器打开 `index.html` 即可，无需构建。

## 6. 风险功能识别

| 功能 | 风险等级 | 风险说明 |
|------|----------|----------|
| Excel导出 | 🔴高 | 涉及文件生成，可能有兼容性问题 |
| 图表绘制 | 🔴高 | Chart.js在不同浏览器表现差异 |
| localStorage存储 | 🟡中 | 存储数据格式变更导致数据丢失 |
| 页面跳转 | 🟢低 | 路由依赖文件路径 |
