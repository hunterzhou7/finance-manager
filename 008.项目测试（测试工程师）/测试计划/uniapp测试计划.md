# 财务管家 - UniApp跨端应用测试计划

## 1. 项目概述

| 项目 | 财务管家 UniApp |
|------|----------------|
| 位置 | 007.跨端APP应用（移动端开发工程师）/uniapp-project |
| 类型 | UniApp跨端应用（Vue3） |
| 平台 | iOS/Android/微信小程序 |

## 2. 技术栈分析

- **框架**: UniApp (Vue3)
- **打包**: HBuilderX
- **API请求**: uni.request
- **存储**: uni.getStorageSync
- **图表**: Canvas 2D（原生canvas）

## 3. 目录结构

```
uniapp-project/
├── App.vue              # 应用入口
├── main.js            # JS入口
├── manifest.json       # 应用配置
├── pages.json         # 页面配置
├── index.html        # 入口页面
├── pages/
│   ├── index/       # 首页
│   ├── add/       # 记一笔
│   ├── statistics/  # 统计
│   ├── history/    # 明细
│   ├── settings/   # 设置
│   ├── login/     # 登录
│   ├── register/  # 注册
│   ├── category/  # 分类管理
│   └── account/   # 账户管理
├── js/
│   └── api.js     # API封装
└── static/        # 静态资源
```

## 4. 启动方式

1. 用HBuilderX打开项目
2. 选择运行平台（iOS/Android/小程序）
3. 运行到模拟器或真机

## 5. 核心业务模块

### 5.1 用户模块
- 用户登录
- 用户登出

### 5.2 记账模块
- 添加支出
- 添加收入

- 账户选择
- 备注

- 明细页（交易列表、分页加载、月份分组）

### 5.4 管理模块
- 分类管理（增删改查）
- 账户管理（增删改查）

### 5.5 设置模块
- 用户信息
- 退出登录

| 功能 | 风险等级 | 风险说明 |
